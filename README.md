# 🚲 Pedal Fácil

**Pedal Fácil** é um site de locação de bicicletas desenvolvido com **HTML, CSS e JavaScript**. O projeto apresenta um catálogo de bicicletas, informações sobre o funcionamento da locação e um formulário para realizar uma reserva.

O objetivo do projeto é criar uma interface moderna, organizada e fácil de utilizar, permitindo que o usuário encontre uma bicicleta adequada para diferentes necessidades, como trilhas, deslocamentos urbanos e passeios.

---

## 📸 Sobre o projeto

O site possui uma página inicial com uma apresentação da empresa, estatísticas, catálogo de bicicletas e uma área para realizar reservas.

A interface foi desenvolvida pensando em uma experiência simples e intuitiva para o usuário.

## 📝 Como funciona

O processo de locação é apresentado em três etapas:

**01 — Escolha sua bike**
Navegue pelo catálogo e escolha o modelo que mais combina com sua necessidade.

**02 — Preencha o cadastro**
Informe seus dados pessoais, endereço e período de utilização.

**03 — Retire e pedale!**
Após realizar a reserva, o usuário poderá retirar a bicicleta no endereço informado pela empresa.

## 📋 Formulário de reserva

A seção **"Finalize seu aluguel"** permite preencher informações como:

### Dados pessoais

* Nome completo;
* Telefone.

### Endereço

* CEP;
* Logradouro;
* Número;
* Bairro;
* Cidade;
* UF.

### Período do empréstimo

* Data de retirada;
* Horário de retirada.

Após o preenchimento, o usuário pode utilizar o botão **"Confirmar reserva"**.

Este projeto foi desenvolvido com o objetivo de praticar conceitos de **desenvolvimento web**, principalmente estruturação de páginas com HTML, estilização com CSS e implementação de interações utilizando JavaScript.

Além da parte técnica, o projeto também busca trabalhar conceitos de **UI (Interface do Usuário)** e organização visual de um site comercial.
